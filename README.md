# ClickGroup releases

Download and update files for the ClickGroup apps. There is no source code in
this repository.

| Release | What it holds |
|---|---|
| `android-apps` | The Android apps — Cashier, Driver, Delivery, Seller, CFD and KDS (`.apk`). The files are replaced when a new version comes out, so the download links stay the same. |
| Desktop releases (`v1.0.3`, …) | The Windows desktop app: the installer (`.exe`) and `latest.yml`, which the installed app reads to update itself. |

Installed ClickGroup apps fetch their updates from here on their own. To
install an app by hand, download it from the release above or from
**Settings → Apps** inside ClickGroup.

Only install ClickGroup apps from this repository or from inside ClickGroup.
